## 관심 분야: 앱·웹 개발

계열제로 입학해 학과가 정해지지 않았던 1학년 2학기, 웹프로그래밍 기초 수업을 들으며 앱·웹 개발에 관심을 갖게 되었습니다. 코드를 쓰면 결과가 바로 화면에 보이고, 직접 만든 사이트가 실제로 돌아가는 것이 재미있어서 그 수업을 듣고 컴퓨터인공지능학부를 선택했습니다.

지금은 그 흥미를 살려 동아리의 불편을 해결하는 [정기모임 신청 사이트](../projects/)를 직접 만들어 운영하고 있습니다.


## 학습 목표

#### 목표: 일상의 불편을 해결하는 서비스를 직접 만들어 앱으로 사용해 보기

동아리 정기모임 신청의 불편을 사이트로 해결해 본 것처럼, 언젠가 제 일상에서 불편한 점을 편리하게 바꿔 주는 서비스를 직접 만들고, 이를 앱으로 바꿔 제가 직접 써 보고 싶습니다. 다만 동아리 사이트를 만들 때 코드 작성은 AI 도구의 도움을 많이 받았기 때문에, 먼저 웹 개발 언어(HTML, CSS, JavaScript) 자체를 제대로 이해하는 것이 필요하다고 생각합니다.


### 실행 계획

1. 이번 겨울방학에 JavaScript 기초를 공부합니다.
2. 일상에서 불편하다고 느끼는 점을 기록해 두고, 그중 하나를 골라 웹사이트로 먼저 만들어 봅니다.
3. 만든 웹사이트를 PWA나 React Native 같은 방법으로 앱으로 바꿔 직접 사용해 봅니다.
